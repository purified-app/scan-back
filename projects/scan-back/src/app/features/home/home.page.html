ScanBack

Scan a QR code or barcode and return to the app you came from

Mobile-first scanner that other web apps can open. After a successful scan, the value is redirected back via URL.

Start scanning Try demo caller

Integration

Open the scanner:

/scan?returnUrl=<urlencoded-https-url>&state=<optional>&formats=<optional>

After a successful scan, redirect to:

<returnUrl>?scanValue=<value>&format=<format>&state=<state>

Demo URL example

Open ScanBack and return to the built-in demo caller:

{{ demoOpenUrl }}

Example return after scanning ABC-123:

{{ demoReturnUrl }}

Without returnUrl, the result is shown in the app (standalone mode). returnUrl must be https: (or http://localhost).
